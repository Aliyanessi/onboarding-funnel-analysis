# Анализ воронки онбординга

## Бизнес-проблема
После изменения онбординга упала конверсия в trial и оплату.
В проекте исследуется, на каком этапе возникает проблема и стабилен ли эффект по сегментам.

## Ключевые метрики
- Конверсия в trial
- Конверсия в оплату
- Конверсия trial → оплата

## Ключевые выводы
- Регистрация → Trial упала на **−10,22 п.п.** (29,5% → 19,28%)
- Регистрация → Оплата упала на **−6,06 п.п.** (12,6% → 6,54%)
- Основное падение происходит на шаге `motivation_selection → onboarding_complete`
- Негативный эффект стабилен во всех странах и на всех устройствах

## Инструменты
SQL, Python (pandas) / Excel

## Данные

| Таблица | Описание |
|---|---|
| `users` | Регистрация, страна, устройство, канал, версия онбординга |
| `onboarding_events` | События и шаги воронки онбординга |
| `sessions` | Активность пользователей по сессиям |
| `retention_flags` | Возвраты пользователей на 1, 3, 7 день |
| `payments` | Данные о trial и оплатах |

Все таблицы связаны через `user_id`.
